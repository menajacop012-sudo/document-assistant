# Document Assistant

Ask questions about a PDF, Word or text file and get answers with page references.

Everything runs locally: embeddings with sentence-transformers, vector search with ChromaDB, and answers generated by a local LLM through [Ollama](https://ollama.com). No API keys, and no document ever leaves your machine.

## Features

- Upload a PDF, Word (.docx) or text file
- Ask questions and get a short answer with the pages it came from
- Ask for summaries ("Summarize the section about SVMs")
- Simple web interface built with Flask (works on a phone over the same Wi-Fi)
- 100% local and free to run

## How it works

1. **Extract**: read the text page by page (`pypdf`, `python-docx`).
2. **Chunk**: clean the text and split it into ~800-character chunks with a 150-character overlap, cutting at sentence boundaries when possible.
3. **Embed and store**: turn each chunk into a vector with `all-MiniLM-L6-v2` and store it in ChromaDB together with its page number.
4. **Retrieve**: embed the question and find the closest chunks.
5. **Generate**: send the question and those chunks to a local LLM (`qwen2.5:7b`), instructed to answer only from the given context.
6. **Return** the answer and the source pages.

Summary requests follow the same flow but retrieve more chunks than a normal question.

## Requirements

- Python 3.10+
- [Ollama](https://ollama.com) installed and running
- About 16 GB of RAM is comfortable for a 7B model. On weaker machines use a smaller model such as `llama3.2` (change `LLM_MODEL` in `app.py`).

## Setup

```bash
git clone <your-repo-url>
cd doc_assistant

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
ollama pull qwen2.5:7b

python app.py
```

Then open http://127.0.0.1:5000, upload a file, and start asking questions.

## Open it from your phone (same Wi-Fi)

1. In `app.py`, change the last line to `app.run(host="0.0.0.0", debug=True, use_reloader=False)`.
2. Find your computer's local IP address (`ipconfig` on Windows).
3. On the phone, open `http://<your-computer-ip>:5000`.

The app has no login, so only do this on a network you trust.

## Docker (optional)

Ollama must be running on your machine (the container talks to it through `host.docker.internal`).

```bash
docker compose up --build
```

Then open http://localhost:5000.

## Limitations

- One document at a time, kept in memory (it is lost when the app restarts).
- Scanned PDFs (images of pages) are not supported; they would need OCR.
- Word files are treated as a single page, and text inside Word tables is not read.
- A summary covers the passages most relevant to the request, not the whole book.
- Answer quality depends on the local model you choose.

## Built with

Flask, ChromaDB, sentence-transformers, Ollama, pypdf, python-docx.
